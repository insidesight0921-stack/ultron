# 다음 작업 — IPO 매력지수 배점 개편 (차등 배점 + 균등 병기)

> 작성일: 2026-08-26 · 결정 완료, 구현 대기
> 대상: `scripts/ipo_bot.py`, `scripts/paper_db.py`, `wiki/투자/IPO_매력지수_기준.md`

## 1. 배경

현재 배점은 5요소 균등 20점이다. 균등 배점은 "어느 요소가 더 중요한지 모른다"는 기본값이지
근거 있는 선택이 아니다. 실증 자료는 수요 강도(경쟁률)의 설명력이 가장 크다고 본다.
자본시장연구원 보고서 기준 청약 경쟁률 구간별 상장일 수익률은 2011~2019년 9.6%(200:1 이하)
대 58.9%(800:1 초과), 2020~2021년 3.8% 대 86.7%로 갈렸다.

`local-ai-agent-plan.md`(설계도)는 차등 배점(경쟁률 35 / 확약 25 / 밴드 20 / 유통 10 / 시총 10)을
제시하는데, 현재 코드와 불일치 상태였다. 이번 작업으로 정리한다.

## 2. 결정 사항

1. **차등 배점을 주 판단에 쓰고, 균등 배점은 기록만 한다.**
   두 점수·등급을 같은 원자료로 함께 계산해 저장하고, 표본이 쌓이면 등급별 예측력 통계에서
   어느 배점이 실제 수익률을 더 잘 갈랐는지 비교한다.
2. **의무보유 확약을 독립 배점으로 분리한다.** 현재는 유통비율 보정값으로만 쓰여 효과가
   점수에 드러나지 않는다.
3. **유통 비율은 보정 없는 원값을 쓴다.** 확약을 독립 배점으로 빼면서 보정을 유지하면
   이중 계산이 된다.

### 채택 배점 (tilted)

| 요소 | 배점 | 근거 |
|---|---:|---|
| 기관 수요예측 경쟁률 | 30 | 수요 강도, 가장 강한 신호 |
| 의무보유 확약 | 25 | 상장 직후 매도 압력 직접 차단 |
| 공모가 밴드 위치 | 20 | 수요 강도의 독립적 확인 |
| 유통 비율 | 15 | 확약과 일부 겹치므로 감점 |
| 상장 시가총액 | 5 | 소형주 효과는 유통비율과 중복 |
| 주관사 티어 | 5 | 대부분 경쟁률·확약에 반영됨, 보조 |

기록용 배점(equal)은 현행 그대로 5요소 20점씩 유지한다(확약은 기존처럼 유통비율 보정).

## 3. 작업 항목

- [ ] `score_lockup(lockup_ratio)` 신설 — 확약 비율(%) → 0~25점. 구간은 아래 초안 참고
- [ ] `score_float_ratio()`에서 `lockup_ratio` 보정 제거 (tilted 계산 경로 한정, 원값 사용)
- [ ] 배점 세트를 상수로 분리
      `WEIGHT_SETS = {"equal": {...20씩...}, "tilted": {"demand":30,"lockup":25,"band":20,"float":15,"size":5,"underwriter":5}}`
- [ ] `compute_attraction_score(item, weights="tilted")` — 두 세트 모두 계산해 반환하도록 확장
- [ ] **환산 로직 수정**: 현재는 `확정 요소 수 × 20`으로 정규화한다. 차등 배점에서는
      `확정 요소들의 배점 합`으로 정규화해야 한다. 이 부분을 고치지 않으면 점수가 왜곡된다
- [ ] 등급 산출 최소 기준 재정의 (아래 미결정 참고)
- [ ] `paper_db.save_ipo_record()`의 `factors` JSON에 두 점수·등급 저장
      (예: `{"tilted": {"score":..,"grade":..,"parts":{...}}, "equal": {...}}`)
      → **DB 스키마 변경 불필요**, factors는 이미 JSON TEXT 컬럼
- [ ] Paper UI IPO 탭: 주 등급은 tilted, 균등 등급은 보조 열로 병기
- [ ] 등급별 예측력 통계를 배점 세트별로 분리 집계
- [ ] `wiki/투자/IPO_매력지수_기준.md` 갱신 — 새 배점표, 확약 독립 배점, 유통 원값 사용 명시
- [ ] `local-ai-agent-plan.md`의 배점표를 채택 배점으로 정정 (설계도와 코드 일치)

### score_lockup 구간 초안 (0~25점)

확약 비율이 높을수록 상장 직후 매도 압력이 낮다. 실데이터 분포 확인 후 조정할 것.

| 확약 비율 | 점수 |
|---|---:|
| 40% 초과 | 25 |
| 30~40% | 21 |
| 20~30% | 17 |
| 10~20% | 12 |
| 5~10% | 7 |
| 5% 이하 | 3 |

## 4. 검증

- 순수 함수 단위 테스트: 각 score 함수의 경계값, 두 배점 세트의 정규화 정확성
- 확약 이중 계산 부재 확인: tilted 경로에서 `score_float_ratio`에 lockup이 전달되지 않을 것
- 기존 기록 회귀: equal 점수가 개편 전 값과 동일해야 한다 (기록용 배점은 안 바뀜)
- 실데이터 1건 이상으로 두 등급이 함께 저장되는지 확인

## 5. 미결정 — 착수 전 확인 필요

- **등급 산출 최소 기준**: 현재는 "확정 요소 3개 이상". 요소가 5개에서 6개로 늘고 배점이
  차등이므로, 개수 기준보다 **확정 요소의 배점 합이 60점 이상일 때만 등급 산출**이 타당해 보인다.
  (경쟁률 30 + 확약 25만 확정돼도 55점이라 등급이 안 나오는 점은 검토 필요)
- score_lockup 구간값 — 실제 확약 데이터 분포를 본 뒤 확정

## 6. 주의

- IPO 페이퍼 기록이 현재 0건이다. **두 배점 비교는 상장 완료 기록이 수십 건 쌓인 뒤에야
  의미가 있다.** 국내 IPO가 월 5~15건이므로 몇 달 단위 작업이며, 그 전에 나오는 차이는
  표본 부족으로 본다.
- 개인 청약 경쟁률은 기관 수요예측과 별개의 설명력이 있으나 **청약 마감 후에 나오므로
  청약 결정 시점에는 쓸 수 없다.** 사후 검증용 변수로만 기록할 것.
- 매력지수는 청약 판단 보조지표이며 자동 주문 근거가 아니다 (기존 원칙 유지).
