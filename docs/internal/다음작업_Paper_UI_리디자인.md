# 다음 작업 — Paper Trading UI 리디자인

> 작성일: 2026-08-26 · 시안 승인 완료, 반영 대기
> 대상: `scripts/paper_ui.py`의 `HTML_PAGE` 상수 (595행~)
> 시안: `docs/paper_ui_redesign_mockup.html` (브라우저로 열어 확인, 탭·필터 동작함)

## 1. 목표

현재 화면은 이모지 라벨, 형광 매수/매도 버튼, 여백·정렬 규칙 부재로 "AI가 만든 화면"처럼 보인다.
정보 구조는 유지하되 시각 언어를 정리한다. **기능·API 변경 없음, 표현 계층만 교체한다.**

## 2. 시안에 반영된 변경

| 항목 | 변경 |
|---|---|
| 이모지 | 탭·제목·버튼에서 전부 제거 |
| KPI 타일 | 상단에 총 평가금액 / 누적 손익 / 코스피 대비 / 보유·거래 4개 신설 |
| 슬롯 배분 막대 | 목표 비율 대비 실제 비중을 한 줄로 표시 (리밸런싱 판단용) |
| 색 | 형광 초록·빨강 버튼 제거. 색은 손익 부호와 슬롯 식별에만 사용. 매수·매도는 테두리 색으로 구분 |
| 숫자 | `font-variant-numeric: tabular-nums` + 우측 정렬 |
| 폼 | placeholder만 있던 입력칸에 라벨 추가 |
| 보유 포지션 | **봇별 그룹** + 그룹 헤더에 봇 합산 손익·수익률. 보유 없는 봇도 자리 유지 |
| 거래 내역 | **시간순 유지** + "봇" 열(색점+이름) 추가 |
| 필터 칩 | 두 표 헤더에 전체/콴텍/키움/IPO/마이퀀트 칩. 거래 없는 봇 선택 시 빈 표 대신 안내 문구 |
| 테마 | 라이트 기본 + `prefers-color-scheme: dark` 자동 전환 |

색상은 색각 이상 분리도·대비 검증을 통과한 4색 팔레트를 사용했다
(슬롯 색: `#2a78d6` `#eb6834` `#1baf7a` `#eda100`, 다크 모드용 스텝 별도).

## 3. 작업 항목

- [ ] `HTML_PAGE`의 `<style>` 블록을 시안의 토큰·컴포넌트 CSS로 교체
- [ ] 헤더·슬롯·탭·주문 폼·표 마크업을 시안 구조로 교체
- [ ] KPI 타일에 실제 값 연결 — `/api/performance`, `/api/paper/portfolios` 활용
- [ ] 슬롯 배분 막대: 목표 비율은 `wiki/투자/분산_슬롯_비율.md`, 실제 비중은 슬롯 평가금액 기준
- [ ] 보유 포지션 그룹핑 + 봇별 합산 손익 계산 (서버 집계 권장, `paper_metrics.py` 재사용)
- [ ] 거래 내역에 슬롯 열 추가 + 칩 필터 (클라이언트 필터로 충분)
- [ ] 기존 탭 6종(차트·키움봇 신호·콴텍봇·IPO봇·나만의 퀀트·성과)의 내부 마크업도 같은
      카드·표 클래스로 통일 — 시안에는 자리만 표시돼 있음
- [ ] Plotly 차트 컨테이너 배경을 새 토큰(`--surface`)에 맞추기

## 4. 주의

- **시안의 숫자는 전부 목업이다.** 실제 값 연결 시 그대로 옮기지 말 것
- 기존 JS 함수(`ipoScan()`, `myquantScan()` 등)의 DOM id를 유지하거나, 바꾼다면 호출부를
  함께 수정할 것. 시안은 id 체계를 단순화해 두었다
- IPO 탭 마크업에 `var(--card-bg)`처럼 정의되지 않은 변수를 쓰는 곳이 있다(모달 배경).
  교체 시 정리할 것
- 반영 후 실제 화면(8080)을 브라우저로 열어 라이트·다크 양쪽을 눈으로 확인할 것
