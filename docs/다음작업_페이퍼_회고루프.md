## 1. 현재 상태

`paper.db` → vault로 가는 경로가 **존재하지 않는다.** vault에 쓰는 스크립트는 세 개뿐이다.

| 스크립트 | 쓰는 내용 |
|---|---|
| `inbox.py` / `inbox_bot.py` | 텔레그램 메모·URL → `raw/inbox/` |
| `refine_raw.py` | raw → Gemma 정제 → `wiki/` |
| `learning_bot.py` | 제안 노트 (경로 수동 지정) |

설계도(`local-ai-agent-plan.md` 6장)의 회고봇(기록봇/평가봇/제안봇)은 미구현이다.
결과적으로 성과는 `paper.db`와 웹 UI에만 있고, 원칙 노트는 성과를 모른 채 그대로다.
설계가 말한 "지식이 성과로 진화하는 역방향 흐름"이 끊겨 있다.

데이터 계층상 vault의 `wiki`·`raw`는 이미 **개인 데이터**(local Gemma 전용, MCP 미노출,
`docs/DATA_CLASSIFICATION.md` 39행)이므로 성과를 여기 적어도 경계는 깨지지 않는다.

## 3. 2단계 — 주간 성과 스냅샷 자동 기록  ⏳ 코드 완료 / 스케줄 등록 대기

**2026-08-26 구현분**: `scripts/paper_weekly_report.py` + `tests/test_paper_weekly_report.py`(25개).
순수 계산·렌더는 완료했고 남은 것은 launchd 등록뿐이다. 수동 실행은 지금도 가능하다.

```
.venv/bin/python scripts/paper_weekly_report.py --stdout        # 노트 미리보기(파일 안 씀)
.venv/bin/python scripts/paper_weekly_report.py                 # wiki/투자/성과/에 저장
.venv/bin/python scripts/paper_weekly_report.py --date 2026-08-19  # 지난 주차 재생성
```


매주 금요일 장 마감 후, `paper_metrics.py`(순수 FIFO 계산 계층, 이미 있음)로 집계해
노트 한 장을 **결정론적으로** 생성한다.

**Gemma 정제를 태우지 않는다.** 숫자를 LLM에 통과시키면 왜곡 위험이 있다. raw→wiki
파이프라인을 쓰지 말고 `wiki/투자/성과/주간_YYYY-Www.md`에 직접 쓴다.
`index_wiki.py`가 `wiki/**`를 인덱싱하므로 RAG는 자동으로 참조하게 된다.

### 노트 형식

```markdown
---
type: paper-weekly
period: 2026-W35
판단시점: 2026-08-21
평가시점: 2026-08-28
---
# 페이퍼 주간 성과 2026-W35

| 슬롯 | 실현손익 | 승률 | 표본 |
|---|---:|---:|---:|
| 콴텍 | +182,400 | 61% | 18 |
| 키움 | −44,100 | 47% | 32 |

## 조건별 (마이퀀트)
| 태그 | 승률 | 손익비 | 표본 |
|---|---:|---:|---:|
| 추세위+눌림 | 58% | 1.4 | 12 |
| 신고가돌파 | 41% | 0.9 | 7† |

† 표본 5건 미만, 참고용

## 적용 원칙
- [[모멘텀_전략_원칙]]
- [[마이퀀트_진입조건]]
```

핵심은 **백링크**다. `[[원칙노트]]`를 걸어 두면 옵시디언 그래프에서 "이 원칙이 어떤 성과를
냈는지"가 역방향으로 조회된다.

## 5. 반드시 지킬 가드 (설계도 6장과 동일)

| 편향 | 방어 |
|---|---|
| look-ahead | 판단시점·평가시점 분리 저장. 평가는 판단시점 정보로만 |
| 과적합 | 최소 표본 미달 시 제안 보류 |
| 확증 편향 | 제안 프롬프트에 "반례 적극 탐색" 명시 |
| 생존 편향 | 실패 사례도 동등 기록 |
| 원칙 오염 | 수정은 항상 사람 승인(HITL) 게이트 경유 |

## 6. 순서

2단계가 3단계의 입력이다. **2단계 없이 3단계를 먼저 하지 말 것.**
1단계(원칙 노트 정합)가 안 되면 백링크 대상이 없으므로 1 → 2 → 3 순서를 지킨다.
